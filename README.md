## 🎨 Visual Design Token Architecture

The user interface follows a systematic three-layer token hierarchy adhering to **Apple-tier Liquid Glass** specifications:

```css
:root {
  /* Primitive Tokens */
  --color-brand-crimson: #c8382b;  /* Royal Crimson Red */
  --color-brand-gold:    #d4af37;  /* Imperial Metallic Gold */
  --color-brand-amber:   #fbbf24;  /* Radiant Amber Gold */
  --color-base-noir:     #050203;  /* Obsidian Noir */
  --color-text-ivory:    #f5ede4;  /* Warm Ivory Text */

  /* Semantic Aliases */
  --color-primary:       var(--color-brand-crimson);
  --color-accent:        var(--color-brand-gold);
  --color-surface-dark:  var(--color-base-noir);

  /* Optical Glass Dynamic Material */
  --glass-liquid-backdrop: blur(24px) saturate(180%);
  --glass-liquid-border:   1px solid rgba(212, 175, 55, 0.24);
  --glass-liquid-shadow:   0 20px 50px rgba(0, 0, 0, 0.85), 0 0 30px rgba(200, 56, 43, 0.2);
}
```

* **Smooth Motion Curves:** Spring physics (`stiffness: 350, damping: 30`) across all interactive cards and floating docks.
* **Inclusive Accessibility:** Built with native support for `prefers-reduced-motion: reduce`, visible high-contrast focus rings (`.focus-royal`), and text contrast ratios exceeding WCAG AAA standards ($> 7:1$).
